
# 🏥 BluePointPharma v6.2.5 - نظام الإدارة المالية والرقابة المحاسبية المتطور

**BluePointPharma** هو منصة سحابية متكاملة مصممة خصيصاً لإدارة الحسابات المالية للصيدليات والشركات الطبية، يجمع بين قوة الذكاء الاصطناعي (Genkit AI) ودقة المحاسبة التقليدية، مع التركيز على مبدأ "فصل السيولة النقدية عن الأرباح الدفترية".

## 🚀 المكونات والميزات الرئيسية:

### 1. لوحة التحكم والنبض التشغيلي (Interactive Dashboard)
*   **الإحصائيات اللحظية**: عرض فوري لإجمالي الإيرادات، المصروفات، الأرباح، ومديونيات الشركات.
*   **شريط الأخبار والنبض (News Ticker)**: مراقبة حالة الصيدلية (مفتوحة/مغلقة)، تواجد الموظفين، ونواقص المخزون بشكل متحرك.
*   **الأهداف الاستراتيجية**: نظام تتبع ذكي يربط المبيعات الفعلية بالأهداف المالية والكمية المخطط لها.
*   **الوصول السريع**: شريط أزرار ذكي لتنفيذ العمليات المتكررة بضغطة زر واحدة.

### 2. المحرك المالي والخزينة (Treasury & Cash Management)
*   **الرصيد التراكمي الموحد**: سجل "دفتر الأستاذ" الذي يطابق نقدية الدرج لحظة بلحظة مع كل عملية بيع أو شراء.
*   **التحويلات البنكية**: إدارة التدفقات المالية بين الخزينة النقدية، الحسابات البنكية، والمحافظ الإلكترونية.
*   **تبادل الأدوية (Inter-Branch)**: نظام لوجستي لإدارة مديونيات الأدوية بين فروع الصيدلية المختلفة.

### 3. المبيعات والمشتريات (Sales & Procurement)
*   **إدارة الشفتات**: تسجيل توريدات الكاشير اليومية وتوثيقها باسم الموظف المسؤول.
*   **مديونية الموردين**: تتبع دقيق لفواتير شركات الأدوية، المرتجعات، وسندات السداد النقدي.
*   **كشوف الحسابات**: استخراج كشوف حساب رسمية للموردين والعملاء (آجل) جاهزة للطباعة والمطابقة.

### 4. إدارة المخزون (Inventory & Valuation)
*   **التدقيق المالي للمخزون**: تسجيل تقييمات دورية لقيمة البضاعة (بسعر التكلفة وسعر الجمهور).
*   **نظام النواقص**: رصد تلقائي للأصناف منتهية الرصيد، مع إمكانية إضافة طلبات شراء يدوية.
*   **الاستيراد الذكي**: محرك استيراد بيانات المخزون والعملاء من ملفات Excel بضغطة زر.

### 5. شؤون الموظفين والرواتب (HR & Payroll)
*   **جدولة الورديات**: إدارة مواعيد العمل، الغياب، والحضور الفعلي.
*   **محاسبة الرواتب**: نظام آلي لحساب الحوافز، الخصومات، والسلف، مع استخراج صافي المرتبات.
*   **الدعم الخارجي (الانتداب)**: قاعدة بيانات للكوادر الخارجية للتشغيل الطارئ.

### 6. المساعد المالي الذكي (AI Integration - Gemini)
*   **AI Insights**: تحليل فوري لسجلات الصيدلية لتقديم ملخص نصي للأداء المالي.
*   **Forecasting**: التنبؤ بالمبيعات المستقبلية وتقديم توصيات إدارية لزيادة الربحية وتحسين التدفق النقدي.

### 7. الأمان والرقابة (Security & Audit)
*   **بوابة PIN الآمنة**: نظام دخول مشفر لكل مستخدم برمز PIN خاص.
*   **مصفوفة الصلاحيات الرباعية**: تحكم جراحي في صلاحيات كل موظف (قراءة، إضافة، تعديل، حذف) لكل قسم بشكل مستقل.
*   **سجل الرقابة (Audit Log)**: توثيق "البصمة الزمنية" لكل حركة تعديل أو حذف تتم في النظام.

### 8. الإدارة المتقدمة والبيانات (Admin & Data Center)
*   **الحساب الختامي**: نظام "قفل الدفاتر" لترحيل الأرصدة وإغلاق الفترات المالية محاسبياً.
*   **النسخ الاحتياطي (Backup)**: محرك Snapshot لتوليد نسخ احتياطية كاملة JSON وحفظها محلياً.
*   **الحذف المفلتر**: أدوات متطورة لتطهير بيانات فترات زمنية محددة دون المساس بالسجلات التاريخية الأخرى.

### 9. نظام الطباعة الاحترافي (Printing System)
*   **طباعة A4**: تنسيقات محاسبية فخمة للتقارير وكشوف الحسابات تتضمن شعار الصيدلية وأختام المسؤولين.
*   **الطباعة المستقلة**: محرك JavaScript لطباعة أي جدول بيانات في نافذة منفصلة بضغطة زر.

---

## 🛠️ المواصفات التقنية (Tech Stack):
*   **Framework**: Next.js 15 (App Router).
*   **Database & Auth**: Firebase (Firestore & Authentication).
*   **Styling**: Tailwind CSS & ShadCN UI Components.
*   **AI Engine**: Google Genkit (Gemini 2.5 Flash Models).
*   **Visualization**: Recharts.
*   **Architecture**: Cloud-Native, Mobile-Responsive, Offline Persistence.
