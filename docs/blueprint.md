# **App Name**: BluePointPharma

## Core Features:

- Dashboard Overview: Displays key financial metrics like total income, expenses, and net profit for customizable periods.
- Income & Sales Tracking: Allows recording daily sales, categorizing income sources, and managing revenue inflows.
- Expense Management: Facilitates entering, categorizing, and tracking pharmacy operational expenses, including supplier payments and overheads.
- Transaction History: Provides a comprehensive list of all financial transactions with filtering and search capabilities.
- Basic Financial Reporting: Generates simple profit and loss statements or cash flow summaries for specific date ranges.
- Secure User Authentication: A system for user registration and login to ensure secure access to financial data for authorized pharmacy staff.
- AI Financial Insights Tool: An AI tool that processes recent financial data to generate concise textual summaries of performance, highlighting trends or significant financial events.

## Style Guidelines:

- The visual scheme will be light to emphasize clarity and professionalism, common for financial applications.
- Primary color: Muted steel blue (#366980), evoking trust and precision essential for financial management.
- Background color: Soft off-white with a subtle cool undertone (#F0F3F5), providing a clean and spacious canvas for presenting financial data.
- Accent color: A vibrant, yet professional blue-violet (#5C71D6), used to draw attention to interactive elements, calls to action, and key data points, creating a distinct visual pop.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, slightly technical feel. Body text font: 'Inter' (sans-serif) ensuring optimal readability for detailed financial information.
- Utilize a consistent set of minimalist, line-based icons for navigation and data representation, enhancing usability without clutter.
- A clean, data-focused layout with ample whitespace to ensure financial reports and dashboards are easy to scan and comprehend. Tables should prioritize legibility.
- Subtle, smooth transitions for UI elements and clear loading indicators for reports, providing a responsive and pleasant user experience.
